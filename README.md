# 📌 Kanban Task Manager

A modern, responsive Kanban-style task management web application built using HTML, CSS, JavaScript, and Bootstrap. This project demonstrates dynamic UI design, task workflow management, and client-side state handling using browser storage.

## 🧠 About the Project

This Kanban Task Manager is a **frontend-based productivity tool** that allows users to organize tasks visually into different stages such as:

- 🟡 To Do
- 🔵 In Progress
- 🟢 Done

The application is designed as part of a **learning project and portfolio showcase**, focusing on UI design, DOM manipulation, and local storage handling.

---

## ⚙️ Features

- 🗂️ Kanban board layout (drag/drop or structured task flow)
- ➕ Add, edit, and delete tasks
- 🔐 Login & Signup pages (frontend authentication using localStorage)
- 💾 Persistent data storage using LocalStorage
- 🎯 Priority tagging for tasks
- 📅 Due date tracking
- 🔍 Search and filter tasks
- 🌙 Dark mode support (if included)
- 📱 Responsive design (mobile + desktop)

## 🧑‍💻 How It Works

1. User signs up / logs in (stored in localStorage)
2. Tasks are created with title, description, priority, and due date
3. Tasks are categorized into Kanban columns
4. Users can update status by moving tasks
5. All changes persist using browser storage
